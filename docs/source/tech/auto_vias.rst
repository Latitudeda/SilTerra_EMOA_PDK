auto_vias.py
====================

Define the vias between different metal line types.

In SilTerra PDK, when two different metal lines are connected, the corresponding vias array will be added auto matically.

Users are allowed to define vias and change related parameters by their own specific requirements. Please see ``technology > vias.py`` and ``components > via > vias.py`` to modify the default vias. Please note that the structure of the vias needs to follow the design rules of **SilTerra**.
